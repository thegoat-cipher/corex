# CoreX Independent Audit — 2026-10-21

Scope: repository snapshot at commit `1bca1c8`, examined with a read-only review. Current counts in the project are higher; this report describes that snapshot.
Toolchain: `source /home/vib/opt/env.sh` → `rustc 1.99.1`, `cargo 1.99.1`, `COREX_LLVM_BIN=/home/vib/opt/llvm20/usr/lib/llvm-20/bin`, LLVM 20.1.8, gcc/cc 15.2.0.

No source, test, or existing documentation file was modified. No git state-changing command was run. The only file created is this `AUDIT.md`.

## 1. Method

1. Built the compiler and ran the full suite; recorded per-binary test counts.
2. Read every claim-bearing document (README, master, ENGINEERING.md, all `docs/*.md`, `docs/grammar.ebnf`) and the implementation (`compiler/src/*.rs`, `compiler/tests/*.rs`).
3. Executed the documented CLI surface and every documented example, plus edge cases for documented semantics (wrapping, masking, aborts, bounds, pointer/array rules, entry, diagnostics, REPL, nesting/stack limits).
4. Checked reproducibility claims (`cargo tree`, `ldd`, emitted IR flags, twin builds).
5. Reran the benchmark harness at 3 runs and compared against the published 5-run numbers.
6. Sampled 33 of the 79 unique URLs cited by `docs/research.md` and `docs/competitor-analysis.md` with `curl -sL -o /dev/null -m 10 -w "%{http_code}"`; all sampled URLs returned 200. Prose claims were not judged by URL.
7. Checked all relative Markdown links in README/master/ENGINEERING.md/docs; none were broken.

Verdict meanings used here: **BLOCKER** = a documented normative behavior is false; **WRONG** = a factual claim is false; **STALE** = a number or list is out of date; **MINOR** = wording, typo, or ambiguity; **UNVERIFIABLE** = cannot be decided with the permitted read-only method.
